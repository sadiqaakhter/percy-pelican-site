# Percy Pelican Website

Static landing page for Marc P. Silvestri's Percy Pelican book series.

## Book Cover

The page looks for the final Book 1 cover at:

`assets/book-1-cover.jpg`

If that file is not present, the site shows a polished cover-style placeholder.

## GitHub Pages

To publish:

1. Open repository Settings.
2. Open Pages.
3. Set source to `main` and `/root`.
4. Save.

The site uses no build step.
